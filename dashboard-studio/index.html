Mapping your data

Select a visual in Design to map its category, value and optional series fields. Counts count rows; means are unweighted averages. Prepare weighted estimates and rates before importing. Null values remain missing.

Design a dashboard brief

Use this studio to explain what a dashboard should show, how it should look and how people should interact with it.

  1. Load data: import CSV or JSON in Data, then map fields to each visual.
  2. Arrange: drag visual headings and resize from their lower-right corners. Snapping aligns edges to 10-pixel points. Turn it off for fine movement, or enter exact pixel values in the inspector. With a heading focused, arrow keys move a visual; Shift + arrow resizes it. Press Delete to delete the selected tile, or use Delete tile in its settings. Undo restores it. Delete continues to edit text normally while a text field is focused.
  3. Set the canvas: click its background or Dashboard settings to edit the title, subtitle, notes, width and height. Fit canvas to content keeps all visuals inside it.
  4. Describe the details: use Design instructions near the top of each visual’s inspector to explain colours, labels, interactions or drill-downs. These notes are included in the saved design and downloaded brief. Text instructions do not automatically implement an interaction.
  5. Test: charts and shared filters are live in Design and Preview. Preview also checks tablet and mobile layouts.
  6. Hand over: download the design brief and save the design JSON. Saved designs include your dataset by default; uncheck this in Data to supply it separately. Export HTML includes the current dataset and a working prototype.

What is supported

Bar, clustered bar, stacked bar, radar, line, area, pie, scatter, heatmap, treemap, Europe map, donut, bubble, histogram and box plot; key figures, tables, text, dropdowns, buttons, sliders and reset controls. Bar, clustered bar and stacked bar each have a horizontal/vertical orientation toggle. Clustered and stacked charts require a series field. Radar charts compare at least three categories on one numeric scale.

All mapped controls filter all data visuals. Chart-click cross-filtering, per-visual filter scopes and custom interactions can be described in the design instructions for the build. Narrow previews stack visuals in reading order.
