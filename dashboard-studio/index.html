Preview calculations

Sum adds values; Count counts rows; Mean is an unweighted average. Scatter, bubble, histogram and box plot use raw observations. Box plots use interpolated quartiles and 1.5 × IQR whiskers, with outliers shown separately. Prepare rates and weighted estimates before loading.

A visual brief for your dashboard

Studio captures your intended layout and the instructions for each visual. It does not generate the final dashboard itself.

  1. Load your data: choose a CSV or flat JSON dataset. Every new session starts blank.
  2. Arrange tiles: add a chart, filter, key figure or text tile. Drag its heading, resize its corner, or use the position and size fields.
  3. Describe each visual: use Visual instructions to explain the question, measures, breakdowns, filters, labels and behaviour you want. The tile type is a starting point.
  4. Preview, if useful: map fields to inspect your data. Unfinished mappings do not prevent saving a brief.
  5. Save and send: Save design downloads a JSON file with your layout, instructions, mappings and, by default, the dataset. Send that file to your dashboard builder.
  6. Continue later: Open design reloads it, including embedded data. If you saved without data, load the source dataset again. Older version 1.0 specifications can also be opened.

Instructions that help the final build

For example: “Compare employment levels across countries for the selected year. Cluster bars by sex, label values in thousands and sort countries by total. Keep the EU aggregate separate. Explain missing values below the chart.”

Download AI brief produces a readable handoff containing the dashboard instructions and every tile description. Give the builder the saved design and dataset as well. Instructions are plain text; Studio does not call an AI service.

Chart choices and limits

Maps show recognised countries and report aggregate or unknown codes separately. The preview uses a single table and global filters. Joins, complex calculations and custom interactions can be specified in the visual instructions for the final build.
